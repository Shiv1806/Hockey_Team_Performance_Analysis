# Data Dictionary

| Field | Meaning | Type |
|---|---|---|
| Team Name | Hockey team name | Text |
| Year | Year/season represented in the supplied data | Whole number |
| Wins | Number of wins | Whole number |
| Losses | Number of losses | Whole number |
| OT Losses | Overtime losses; blank in supplied source | Numeric / Missing |
| Win % | Winning percentage | Decimal |
| Goals For (GF) | Goals scored by the team | Whole number |
| Goals Against (GA) | Goals conceded by the team | Whole number |
| + / - | Goal differential supplied by the source | Whole number |
| Goal Differential | Derived: Goals For minus Goals Against | Whole number |
| Performance Category | Derived Win %-based performance grouping | Text |

## Metric interpretation

**Goals For (GF)** = goals scored.

**Goals Against (GA)** = goals conceded/allowed to opponents.

**Goal Differential** = Goals For − Goals Against.

**Win %** = proportion of games won.

**Performance Category** = derived grouping used for dashboard segmentation.
