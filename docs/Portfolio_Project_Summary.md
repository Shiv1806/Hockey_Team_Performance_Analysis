# Portfolio Project Summary

## Hockey Team Performance Analysis

### One-line portfolio description

Built an end-to-end hockey performance analytics solution using Python web scraping, Pandas, data transformation and Power BI to convert raw web data into an interactive dashboard and actionable performance analysis.

### Project objective

Collect, prepare and analyse hockey team performance data and communicate the results through interactive Power BI visualisation.

### End-to-end work completed

1. **Web scraping**
   - Requests
   - BeautifulSoup
   - HTML table extraction
   - Pandas DataFrame creation

2. **Data preparation**
   - Structured raw records
   - Reviewed data types
   - Reviewed missing values
   - Prepared analysis-ready fields

3. **Transformation**
   - Goal Differential
   - Performance Category
   - Analytical aggregation choices

4. **Validation**
   - Reviewed Win %
   - Wins/Losses
   - Goals For/Against
   - Goal Differential
   - Missing OT Losses

5. **Analysis**
   - Team performance comparison
   - Offensive analysis
   - Defensive analysis
   - Goal Differential analysis
   - Correlation analysis
   - Performance segmentation

6. **Power BI**
   - 8 KPI cards
   - Team and Year slicers
   - Bar chart
   - Pie chart
   - Scatter plot
   - Combination charts

### Key quantified findings

- Highest Win %: Detroit Red Wings — 75.6%
- Highest Goals For: Pittsburgh Penguins — 362
- Lowest Win %: Ottawa Senators — 22.0%
- Lowest Goal Differential: San Jose Sharks — −105
- Goal Differential vs Win % correlation: approximately 0.97
- Goals For vs Win % correlation: approximately 0.69
- Goals Against vs Win % correlation: approximately −0.72
